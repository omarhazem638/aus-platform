📱 Android APK
══════════════
  المشروع جاهز في: aus-apk\

  خيار A — Android Studio (موصى به):
  ────────────────────────────────────
  1. نزّل Android Studio: https://developer.android.com/studio
  2. افتح Terminal في مجلد aus-apk\
  3. npx cap open android
  4. في Android Studio: Build → Build APK(s)
  5. APK في: aus-apk\android\app\build\outputs\apk\debug\

  خيار B — PWABuilder.com (أسرع، بدون تثبيت):
  ──────────────────────────────────────────
  1. شغّل START.bat أو AUS-Simulator.exe
  2. افتح: https://www.pwabuilder.com
  3. أدخل: http://localhost:5180
  4. اختر Android Package → تنزيل APK
     (APK رسمي موقّع يعمل على معظم الأجهزة)

  خيار C — مباشر على الهاتف (PWA):
  ──────────────────────────────────
  1. شغّل المحاكي على الحاسوب (نفس الشبكة WiFi)
  2. ابحث عن IP الحاسوب: ipconfig → IPv4
  3. افتح Chrome على الهاتف: http://192.168.x.x:5180
  4. Chrome → ⋮ → إضافة إلى الشاشة الرئيسية
  (يعمل كتطبيق حقيقي — أيقونة، وضع ملء الشاشة)
